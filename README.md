## معرفی

RastAI یک افزونهٔ مرورگر برای نمایش درست متن‌های فارسی، عربی، عبری، اردو و
پشتو در رابط‌های گفت‌وگو است. افزونه جهت هر پاراگراف را جداگانه تشخیص می‌دهد
تا متن فارسی راست‌چین بماند و هم‌زمان کد، مسیر فایل، آدرس، نام متد و عبارت‌های
انگلیسی جهت صحیح خود را حفظ کنند.

تمام پردازش‌ها داخل مرورگر انجام می‌شوند؛ افزونه هیچ داده‌ای ارسال یا دریافت
نمی‌کند و به سرویس جانبی وابسته نیست.

## امکانات

- تشخیص هوشمند جهت هر پاراگراف، بدون اتکا به طول کلمات
- سه حالت نمایش: **هوشمند**، **همیشه راست‌چین** و **بدون تغییر جهت**
- راست‌چین‌شدن خودکار کادر نوشتن هنگام تایپ فارسی
- نمایش صحیح جدول‌های فارسی همراه با حفظ جهت مستقل هر سلول
- ایزوله‌کردن کدها، شناسه‌ها، URLها و عبارت‌های لاتین داخل متن راست‌به‌چپ
- نمایش پیکان‌ها در جهت خواندن متن، بدون تغییر محتوای قابل کپی
- فونت اختیاری [Vazirmatn](https://github.com/rastikerdar/vazirmatn)
- تنظیم اندازهٔ متن و فاصلهٔ سطرها
- سه پیش‌تنظیم خوانایی: فشرده، عادی و راحت
- اصلاح دستی جهت یک پاراگراف با دکمهٔ کناری یا میان‌بر `Alt+Shift+F`
- ذخیرهٔ اصلاح‌های دستی و امکان پاک‌کردن همهٔ آن‌ها
- کلید روشن/خاموش مستقل برای هر سایت
- حالت تشخیص برای بررسی قاعدهٔ اعمال‌شده روی هر پاراگراف
- کپی متن بدون افزودن کاراکترهای نامرئی

## نصب

### نصب از Releases

1. آخرین نسخه را از صفحهٔ [Releases](https://github.com/AliMirzad/RastAi/releases)
   دریافت و از حالت فشرده خارج کنید.
   در صورت نیاز می‌توانید صحت فایل را با مقدار منتشرشده در
   `SHA256SUMS.txt` بررسی کنید.
2. در Chrome یا مرورگرهای مبتنی بر Chromium وارد `chrome://extensions/` شوید.
3. گزینهٔ **Developer mode** را فعال کنید.
4. روی **Load unpacked** بزنید و پوشهٔ استخراج‌شده را انتخاب کنید.
5. تب‌های گفت‌وگوی باز را یک بار تازه‌سازی کنید.

### نصب از سورس

```bash
git clone https://github.com/AliMirzad/RastAi.git
cd RastAi
```

سپس پوشهٔ پروژه را با گزینهٔ **Load unpacked** به مرورگر اضافه کنید.

## استفاده

پس از نصب، RastAI به‌صورت خودکار روی سایت‌های پشتیبانی‌شده فعال می‌شود. با
بازکردن پنجرهٔ افزونه می‌توانید:

- حالت تشخیص جهت را تغییر دهید؛
- فونت، اندازهٔ نوشته و فاصلهٔ خطوط را تنظیم کنید؛
- افزونه را فقط برای سایت فعلی خاموش یا روشن کنید؛
- اصلاح‌های دستی ذخیره‌شده را مشاهده و پاک کنید؛
- حالت تشخیص را برای بررسی نتیجهٔ موتور فعال کنید.

برای تغییر دستی جهت پاراگراف، بخشی از متن آن را انتخاب کنید و دکمهٔ ظاهرشده را
بزنید. میان‌بر `Alt+Shift+F` نیز همین کار را انجام می‌دهد. اجرای دوبارهٔ
میان‌بر، اصلاح دستی را حذف می‌کند و پاراگراف را به تشخیص خودکار برمی‌گرداند.

## حریم خصوصی

RastAI:

- درخواست شبکه‌ای ایجاد نمی‌کند؛
- تله‌متری یا ابزار تحلیل رفتار ندارد؛
- کد راه‌دور دریافت یا اجرا نمی‌کند؛
- محتوای گفتگو را از دستگاه خارج نمی‌کند؛
- تمام تنظیمات و اصلاح‌ها را در `storage.local` نگه می‌دارد.

مجوزهای افزونه به این دو مورد محدود شده‌اند:

| مجوز | کاربرد |
|---|---|
| `storage` | ذخیرهٔ تنظیمات و اصلاح‌های دستی |
| `activeTab` | اعمال تغییرات پنجرهٔ افزونه روی تب فعال |

## موتور تشخیص جهت

موتور RastAI به‌جای شمردن حروف، ساختار نثر را بررسی می‌کند. کدهای داخل خط،
لینک‌ها و شناسه‌های فنی پیش از تصمیم‌گیری از نثر اصلی جدا می‌شوند؛ سپس شروع
جمله، تعداد واژه‌ها و شکل ترکیب بخش‌های فارسی و لاتین بررسی می‌شود.

نتیجه برای ورودی یکسان همواره ثابت است و تصمیم‌گیری به ترتیب پردازش صفحه یا
طول یک شناسهٔ فنی وابسته نیست. جزئیات معماری و قواعد تشخیص در
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) مستند شده‌اند.

## توسعه و آزمون

پیش‌نیاز اجرای آزمون‌ها [Node.js 22 یا جدیدتر](https://nodejs.org/) است. آزمون‌های مرورگری
به Chrome یا یک مرورگر Chromium نیاز دارند.

```bash
# مجموعهٔ اصلی تشخیص جهت
node tools/accuracy.js

# مجموعه‌های مستقل و BiDi
node tools/accuracy.js tools/holdout.json
node tools/accuracy.js tools/bidi-corpus.json

# هماهنگی دامنه‌ها و manifest
node tools/audit.test.js
node tools/match.test.js

# آزمون‌های مرورگر و رابط کاربری
node tools/browser-tests.js
node tools/ui.test.js

# بنچمارک‌ها
node tools/bench.js
node tools/browser-bench.js
```

بنچمارک مرورگر، مصرف CPU پردازشگر صفحه را با زمان واقعی و افزونهٔ روشن/خاموش
می‌سنجد؛ تایمرها یا زمان‌بندی مرورگر را جایگزین نمی‌کند. برای مقایسه با یک
نسخهٔ قبلی از `content.js`:

```bash
node tools/browser-bench.js --baseline path/to/previous/content.js --runs 3 --size 600 --json
```

انتخاب مرورگر با `CHROME_PATH` یا `CHROME` ممکن است. این ابزار فقط از پروفایل
موقت مستقل استفاده می‌کند و به تب‌ها یا حساب‌های مرورگر شخصی دست نمی‌زند.

مجموعهٔ فعلی بیش از ۸۰۰ بررسی خودکار برای موتور جهت، BiDi، جدول‌ها، تایپوگرافی،
رابط افزونه و تنظیمات دارد.

## ساختار پروژه

```text
background.js          مدیریت میان‌بر صفحه‌کلید
content.js             پردازش DOM و اعمال جهت و تایپوگرافی
engine.js              موتور خالص تشخیص جهت
match.js               تطبیق URL با الگوهای manifest
popup.html/js/css      رابط و تنظیمات افزونه
sites.js               وضعیت پشتیبانی سایت‌ها
fonts/                 فایل‌های فونت Vazirmatn
icons/                 آیکون‌های افزونه
tools/                 آزمون‌ها، بنچمارک و ابزار ساخت
docs/ARCHITECTURE.md   مستندات فنی
```
